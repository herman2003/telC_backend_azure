# Spec: unused AI Speaking credits (policy)

## Status

Folded into the assign/remove model.

**Source of truth:** [AI_SPEAKING_CREDITS_ASSIGN_SPEC.md](./ai-speaking-credits.md)  
**Plan:** [AI_SPEAKING_CREDITS_ASSIGN_PLAN.md](../archive/ai-speaking-credits-assign-plan.md)

## Policy (summary)

| Situation | Rule |
|-----------|------|
| Assigned, not used | Stay on the seat until spent or removed |
| Manager removes assignment | Unused → school **unallocated** stock |
| Short auto-expiry | None (v1) |
| Lapsed Start | Freeze; keep balances |
| Refund to payment method | Manual support only |

This policy only makes sense with **assign-from-stock** (not the old “cap over shared pool” semantics).
